演習の進め方

  • サンプルコードを見て、すぐ下の入力欄に自分で打ち込みます。
    • 入力欄への貼り付けはできません。
  • 「実行する」を押して、表示された結果を確認します。
    • 最初の実行では、準備に時間がかかることがあります。
    • 終わらないときは「停止する」を押します。
  • 入力内容は、使っているブラウザに自動保存されます。
    • 同じブラウザでこのページを開くと、入力を続けられます。
  • 最後に出席番号と氏名を入力し、提出用ファイルを保存します。
    • 保存したHTMLファイルをMoodleに提出します。

Javaとは

  • Javaは、コンピュータに処理の手順を伝える「プログラミング言語」の一つです。
    • 前期のPythonに続いて、後期はJavaでプログラムを作ります。
  • プログラムを書いた文字の並びを「ソースコード」と呼びます。
    • Javaのソースコードは、名前の末尾が .java のファイルに保存します。
  • ソースコードを実行用の形式へ変換することを「コンパイル」と呼びます。
    • 書き方に誤りがあると、コンパイル時にエラーが出ます。
    • 変換したプログラムは、Javaの実行環境で動かします。

  • public class Main { ... } は、プログラムを入れる外側のまとまりです。
    • このまとまりを「クラス」と呼びます。ここでは Main という名前を付けています。
    • このコードのファイル名は、クラス名に合わせて Main.java にします。
    • 

  • public static void main(String[] args) { ... } の中に、最初に実行する処理を書きます。
    • 今回は、この行を基本の形としてそのまま使います。
    • クラス名の Main と、この行の main は、大文字・小文字が異なります。
    • 

  • System.out.println(...) は、括弧の中の内容を表示して改行します。
    • 文字の並びを「文字列」と呼び、半角の二重引用符 " で囲みます。
    • 表示する命令の最後には、半角のセミコロン ; を付けます。
    • 

  • { と } は、処理のまとまりを囲みます。
    • 内側の行は、行頭に空白を入れるとまとまりが分かりやすくなります。

エラーの直し方
    

  • コンパイル時にエラーが出たら、示された行とその前後を確認します。

      

    • セミコロン ; や二重引用符 " が抜けていないか確認します。
      • 

    • 開く括弧 (・{ と、閉じる括弧 )・} が対応しているか確認します。
      • 

    • System の先頭は大文字、println の最後は小文字の l と n です。
      • 

    

    • 

  • プログラムの記号には半角を使います。

      

    • 二重引用符の内側には、日本語や全角の記号も書けます。
      • 

    

    • 

  • 一つずつ直し、もう一度コンパイルして実行します。

      

    • 実行できても、表示内容が目的どおりか確認します。
      • 

    

    • 



確認
最初のサンプルで println の行末の ; を一度消し、エラーを確認しましょう。
確認したら、; を戻して再び実行します。
