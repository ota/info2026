## 第1回の方針

- 到達目標の「実行方法」と「簡単な出力」に合わせる。
- 見本は2つ。Hello Worldと、改行の有無を比べるコードを扱う。
- 自力で取り組む課題は、好きな文字列、自己紹介、山形模様の3問。
- クラスと `main` は基本の形として示す。詳しい仕組みは後の回で扱う。
- 変数・型・計算は第2回で扱う。第1回の自己紹介も文字列だけで作る。
- 第1回用にTeaVM実行環境を接続済み。通常の静的ビルドでも実行できる。
  - 第2回以降の機能と、演習室での動作確認は残る。

## 実行環境に必要な機能

| 区分 | 必要な機能・確認事項 |
| --- | --- |
| 第1回から必要 | `Main.java` のコンパイルと実行、日本語の出力、printとprintln、コンパイルエラーの表示 |
| 後期の範囲から必要 | 数値・文字列、分岐、ループ、配列、メソッド、クラスとオブジェクト |
| 運用上必要 | 無限ループの停止、停止後の再実行、入力コードの復元、結果を含む提出HTML保存 |
| 採用前に検証 | 標準入力、実行時エラー、連続実行、演習室での一斉利用 |
| 教材設計により判断 | Scannerの導入時期、実行途中の入力、複数ファイルへの分割 |

- 後期のシラバスにはScanner、GUI、複数ファイルの指定はない。
  - これらを必修範囲と推測しない。クラスの導入は1ファイルでも作成可能。
  - ただし標準入力が使えるかは、後の演習の選択肢に関わるため採用前に確認する。
